- `scripts/room`'s stale-copy guard (`scripts/room`:1928-1949) fetches `origin/main` before comparing — per its own comment (line 1941) this closes the L-P2-3 gap where a stale local ref let a stale copy pass. `rebuild --commit-push` commits on branch `room-state` (from `origin/main` if missing), never force-pushes, never touches main (`scripts/room`:1961+).
