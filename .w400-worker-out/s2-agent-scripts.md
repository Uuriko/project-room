### Behavioral notes

- `agent-inbox.mjs` command surface (from `--help`, agent-inbox.mjs:281-340): connect, import, check, search, find, work, result, discussion, orient/next/brief/context/changes/packet, presence, capabilities, advertise, say, outside-agents, templates/room-templates/apply-template, export, import-history, thread, notify, heartbeats, rooms, identity-create, join, bootstrap-agent-room, room-create, account-link, identity-link(s)/identity-unlink, leave-room, invite-code(s)/invite-code-revoke, agent-keys (create/list/rotate/revoke), redeem-invite, request-access, access-requests, access-decide, membership-grant/revoke/grants, doctor, support-export, sessions, claim, session, work-claim, work-complete, work-release. `watch` and `reply` are separate imported subcommands, not in that validation list (agent-inbox.mjs:405-407).
- Credential hygiene is enforced in code, not just docs: `connect`/`import` refuse when `ROOM_AGENT_CONFIG` is already set (never overwrite), and `import` refuses when any `ROOM_AGENT_*` var is set (agent-inbox.mjs:405-409). "Never put a key in a prompt, URL or command argument."
- `redeem-invite` has an interactive consent gate: `--yes` skips, `--no` reviews the grant and aborts (scripted decline); abort prints to stderr and exits 1 with no identity created (agent-inbox.mjs:250-259).
- `agent-watch.mjs` v1 `start` directories and v2/v3 `pull` directories are incompatible by design — the help text warns "Do not reuse a v1 start directory for pull. No automatic migration or reset occurs." (agent-watch.mjs:13-34).
- `agent-doctor.mjs` deliberately conflates 401-on-identity-secret: the repair text says the server response "cannot distinguish an invalid or revoked secret from missing room access" and instructs NOT to create another identity to repair it (agent-doctor.mjs:128-133).
- `agent-work-preflight.mjs` is advisory-only: its report JSON includes the boundary "No room writes, approval, test-suite result, merge or deploy" (agent-work-preflight.mjs:72-79), and `needsReview` treats "behind-or-diverged" or a dirty tree as review-needed, not as failure.
- The four Playwright checks share the acceptance-fixture pattern (`createAcceptanceFixture` + in-process `createRoomServer`) and abort any off-origin network request in tests, so they fail closed on unexpected external calls.
- STALE `docs/CLAUDE-CHANNEL.md:14` — ""The server command is `channel/serve.mjs`, which runs `scripts/room-listen.mjs --mode channel` from a Project Room source checkout"" contradicts `plugins/project-room/channel/serve.mjs:38` (`await main();` — no `--mode` passed) plus `scripts/room-listen.mjs:10` (parseArgs throws `usage_error` unless `argv[0] === '--mode'`) and `scripts/room-listen.mjs:97` (`main(argv = process.argv.slice(2))` defaults to the host's argv). serve.mjs relies on the host passing `--mode channel` itself; it does not select the mode the way `agent-claude-channel.mjs` does. (The same doc's example config at line 54 correctly spawns `agent-claude-channel.mjs` with explicit `--mode`-preselected args.)
