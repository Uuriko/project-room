# Merge checklist

Superseded by [RULES.md](../../RULES.md): anyone may merge a green PR, and
review is advisory.

The only merge requirements left are that main stays green and that no
secret is printed. Run the tests that cover your change, merge, then check
main's CI and fix forward if it breaks.
