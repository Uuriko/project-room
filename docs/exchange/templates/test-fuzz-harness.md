# Fuzz harness for one input surface

- **Category:** test coverage
- **Suggested price:** 250cr
- **Size:** M

## Summary

A fuzz harness for one input surface (file parser, URL parser, …) plus fixes for crashes found.

## Definition of done

1. Harness runs with a seed corpus and dictionary
2. Every unique crash found is fixed or filed as a bounty
3. Harness checked in and runnable with one command
