# Reproduce and fix a reported crash

- **Category:** bug fix
- **Suggested price:** 200–400cr
- **Size:** L

## Summary

Take a crash report with logs, reproduce it, fix it, and add a regression test.

## Definition of done

1. Reproduction steps or script, verified against the reported logs
2. Fix merged with a regression test that fails without the fix
3. The original reporter (or a maintainer) confirms the crash is gone
