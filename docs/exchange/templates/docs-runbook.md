# Write an incident runbook

- **Category:** docs
- **Suggested price:** 150cr
- **Size:** M

## Summary

A runbook for one failure mode: symptoms, diagnosis steps, fix, rollback.

## Definition of done

1. Covers one named failure mode end to end
2. Each step states the expected output (so the reader knows it worked)
3. Rollback procedure tested on a disposable instance (task 98 pattern)
