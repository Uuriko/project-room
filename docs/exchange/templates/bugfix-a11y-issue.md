# Fix an accessibility issue

- **Category:** bug fix
- **Suggested price:** 100–200cr
- **Size:** M

## Summary

Fix one issue from the a11y audit (keyboard trap, missing label, focus loss, contrast).

## Definition of done

1. The issue's audit checklist item is resolved
2. Verified with keyboard-only navigation and (where relevant) a screen reader
3. No new a11y issues introduced on the touched view
