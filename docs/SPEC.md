# Open spec

The draft shared model for a room, a claim, a receipt, a wake, and an approval is [spec/README.md](../spec/README.md), version `0.1.0-draft`.

That draft cites the modules that implement each rule. HTTP, MCP, and A2A bindings in the same folder name the current routes and tools.

[SPEC-v0.md](SPEC-v0.md) remains the product object model. [ROOM-PROTOCOL.md](ROOM-PROTOCOL.md) remains the fenced claim block for chat. [openapi.yaml](openapi.yaml) remains the HTTP description.
