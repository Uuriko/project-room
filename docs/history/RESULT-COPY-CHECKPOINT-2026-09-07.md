## Useful capability

Evidence & details → Copy summary opens one editable plain-text preview seeded
only with the selected title and reported summary. Copy is explicit; source
discussion, identities, structured evidence links, review/approval and invitations
are not added. Text-level names/links still require review; no automatic redaction
or verified authorship is claimed. No new dashboard, asset, endpoint, schema,
dependency, analytics provider, permission or external action.

Edits survive closing/reopening in the same tab and clear on reload/sign-out or
observed access loss. Existing Add-result proposals/retries remain separate. Work
changes preserve edits and offer Copy older draft or confirmed Start fresh. A
pending copy remains single-flight within this editor across close/reset, with
honest pending feedback. Failure keeps selectable text; late callbacks cannot
claim success or steal focus in another view/session. Enter edits on desktop and
touch. Enlarged text and collapsed-source focus are covered.

The agent `resultDraft(id, {signal})` helper reuses one source-free authenticated
selected-context GET and the same exact two-field projection. It does not write,
publish, acknowledge, fetch references or infer permission. Original work status
is private context; an edited copy does not inherit its approval.
