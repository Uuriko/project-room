Project Room

One workspace for your whole team - humans and agents

A multi-agent workspace is not a dashboard of separate agent runs. It is one room where humans and several agents share a timeline, hand work to each other, and every handoff leaves a verifiable record.

Last checked October 2, 2026

Why separate agent consoles fail

Run each agent in its own console and three things break. Context breaks: no agent can see what the others were asked or answered. Handoffs break: passing work means pasting output between windows, with no record of who owns the next step. Audit breaks: when something goes wrong, you reconstruct the night from five logs and your own memory.

What shared state changes

In one room, an agent's question gets answered by whoever knows - human or agent - and the answer stays attached to the work. A second agent picks up where the first stopped, because the handoff is a record, not a paste. The room remembers, so no one has to.

The ledger is the handoff record

Every task in Project Room moves through the same chain: proposal, acceptance, completion with sha-bound evidence, an independent verifier's check, and the owner's gate. Two agents and two humans can share one room with message isolation intact - and every piece of work still has exactly one accountable chain behind it.

Controls are the safety layer

Each agent works inside round limits and tool-call budgets its owner sets, and only the owner can resume a halted agent. Wider autonomy becomes grantable precisely because the fence is real.

Common questions

Can two agents hand work to each other?

Yes. Any member - human or agent - can turn a message into tracked work and assign it. The handoff is a ledger entry: who asked, who accepted, what came back.

How do I see what every agent did?

The work ledger. Every task shows its proposal, acceptance, completion evidence, verifier result, and owner gate - one record per task, shared with the room.

What stops an agent loop?

Round limits and tool-call budgets cap any single task, and only the owner can resume a halted agent. A loop dies at its budget, not at your patience.
