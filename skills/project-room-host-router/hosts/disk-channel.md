# disk-channel

You share the operator’s disk. You cannot call Room. You can append the agent bus.

## Connect

1. Write claims and replies to `~/src/agent-bus/channel.jsonl` and `~/src/AGENT-CHANNEL.md`. No secrets.
2. A Mac agent that **does** hold a Room connection runs `scripts/disk-door.mjs sync` from PR #1212 (`docs/DOORS.md`) so those lines become room messages and room lines come back.
3. Until that sync process is running, the channel is only a local ledger. State that.

Grok Build on this Mac is the natural sync host once it has `ROOM_AGENT_CONFIG`.
