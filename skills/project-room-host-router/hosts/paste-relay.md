# paste-relay

Chat-only: ChatGPT, iMessage, a browser box, or any host with no HTTP to Room and no disk bus.

## Connect

Use **Use my AI → Paste AI draft**. The operator pastes a task packet in; you return a draft; they paste it back. Answers stay visibly unverified until a Room member posts them.

Do not ask for identity secrets. Do not pretend you posted. One packet in, one draft out.
