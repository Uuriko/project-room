## 3. What fantastic means

One **Search Coherence Contract**, published and machine-pinned, such that a caller can predict every surface from any other:

- **Honesty, 100%, no exceptions.** Every query key on every search-bearing surface (S1, S4, S5, S6, plus controls S7) is either honoured or refused **422 naming the accepted set** — measured as a matrix, not a sample: the §5 sweep runs every surface × {each honoured key, each known synonym (`q`/`search`/`query`/`filter`/`after`/`cursor`/`before`/`format`/`sort`/`kind`), one nonsense key, one repeated honoured key} and the result is **0 silent ignores** (a 200 byte-identical to the unfiltered response for a non-honoured key is a failure by definition). #5138's critic numbers for its surfaces (refused 22/22, accepted 25/25) must still hold *and* S4 must join them.
- **One published table tells the whole truth in one screen.** For each of S1–S7: param name for the query (`q` everywhere a text query exists), accepted keys, fields searched, matching rule (substring-phrase vs token-AND), fold rule, order (newest-first / ranked-best-first / triage / `at DESC, id ASC`), tiebreak, limit + default, cursor name + binding + stale behaviour, whether a `total` exists and what it counts, and error codes. A reader who has only read the table makes **zero** wrong predictions on the §5 probe corpus.
- **Declared differences, zero undeclared ones.** Work-order (S1 creation-newest vs S2/S3 triage), work/message field sets, inbox's no-pagination ranked cut (at most 200, `total` honest, nothing beyond the cut is reachable and the doc *says so*), receipts' absence of text search and of `total`, and `mentions:me` being client-only are each stated in the table and in the owning operation's OpenAPI description — and the §5 cross-surface probe *pins* each declared difference, so changing one becomes a deliberate, test-breaking act.
- **Cursors fail closed across surfaces, 100%.** Every ordered pair (cursor minted on surface A, presented to surface B ≠ A) in the §5 walk returns 422 — never a 200, never a page 1. Within-surface walks still partition exactly: the SC critic's property (23-hit union exact, no drops, no duplicates) holds for S1 after *all* prerequisites land, including after any #4862 rebase.
- **Hidden means invisible, everywhere, measurably.** For each hiding mechanism (deleted/redacted message, pre-join history floor, muted author, third-party targeted DM, unpinned-under-`kind=pinned`, quarantined inbox source, channel source without `view`, operator-unpublished receipt, owner-toggled-off receipt, non-opted-in lot): hits absent, `total` identical to a world where the item never existed, and a cursor naming it returns the same 422 body as a cursor naming a never-existent id.
- **Docs agree with each other.** The search operations in `docs/openapi.yaml` (generated from fragments), the served `/openapi.json`, and the executed behaviour form a triangle with no contradictory side: any search operation absent from the served inventory is absent under the inventory's own stated curation scope, not by drift.
- **Exemplars:** the in-product controls are the exemplar — `/api/project-offers` and `/api/public-work/tasks` already refuse honestly; match them. Externally, match GitHub's search API discipline (one documented parameter vocabulary per resource, unknown parameters never silently reinterpreted) — do not copy its query DSL; there is no new DSL in this pack.
