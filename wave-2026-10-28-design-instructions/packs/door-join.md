## 1. The piece

The stranger's conversion surface: a person or agent holding an invite link, a bare `RM-…` code, a room address, or nothing at all lands here and either joins a room, requests access, or leaves. It is unauthenticated and stateless by design.

Verified against source read via `git archive aaa749065a` into this lane's scratch (the shared clone was not used):

**Page and routes**

- `join.html` — 6,183 B at main. Five states in one file: `#join-loading` (with `<noscript>` fallback), `#join-enter` (paste link/code), `#join-request` (request-access `<details>`: room, display name, note, referrer — pre-filled `muse-room`), `#join-consent` (room title, inviter, permissions list, expiry, one name field, one **Join room** button), `#join-success` ("You're in", **Open room** link, and the once-only agent key in `#join-secret` behind `<summary>Agent key (once)</summary>`), `#join-error`.

## 3. What fantastic means

A stranger with an invite link is in the room in under a minute, on a page that weighs less than the email that carried the link, and a screen-reader user is never grabbed, lost, or lied to on the way.

Concrete end state, all measurable:

- **Weight:** cold `/join` totals **≤ 200 KB raw** across HTML + CSS + JS (the PERF-50 target class), stretch ≤ 140 KB; **≤ 10 requests**; the initial JS closure contains **no `client.js`, `events.js`, `share-links.js`, or `work-*.js`** — initial JS ≤ 110 KB raw, with the room-client graph reachable only as a lazy chunk loaded when (and only when) the request-access form is actually submitted.
- **CSS:** the join page no longer pays the 143 KB application stylesheet. A join/public-form stylesheet of **≤ 20 KB raw** carries its classes; visual output is pixel-equivalent for the five states (visual-regression pins hold).
- **Steps:** invite link → consent screen → **one field (name) + one click** → success with **Open room** as the primary action and the agent key one disclosure away. No-code path: paste link/code → Continue → same consent. Request-access path: one disclosure, four fields, one submit. Zero steps added by this pack; two failure detours removed (retyping after refresh; landing in a field you didn't choose).
- **Focus:** on load, focus is where the browser left it (document body); the first Tab lands on the first interactive element in DOM order. Every field on the page has a **unique** accessible name, including `#join-secret` ("Agent key").
- **No silent data loss:** refresh at any point before submit restores every typed character; a successful submit or a navigation to `/join/<code>` clears the draft.
- **No false claims:** `/rooms/<id>` for an unchecked id never asserts the room exists; its copy offers the code entry and the request path without naming the room as fact.
- **Agent packet:** `llms.txt`'s named-room section is self-contained — mint + join steps in-packet, in order, with the setup skill as a supplement, not the only road.
- **Exemplars to match:** in-product, the `/offers` page (PERF-50 A5: 42,329 B total, standalone UI module, no import graph) for weight discipline, and the public receipt detail (UT2 10-04: the only audited surface with the complete landmark set) for structure. The bar is the product's own best surfaces, not an external site's.
