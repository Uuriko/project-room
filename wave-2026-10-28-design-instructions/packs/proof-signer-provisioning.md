## 3. What fantastic means

The channel exists, is boring, and can be armed in one sitting without an engineer improvising anything — and until that sitting, it changes nothing:

- **Provisionable in one named step.** A seed can reach the signer through exactly one documented channel: env names `ROOM_RECEIPT_SIGNER_SEED` / `ROOM_RECEIPT_SIGNER_REF` (the #4807 names — do not invent new ones), read at `RoomStore` construction, passed explicitly at **every** serving construction (`server.mjs`, `cloudflare/room.mjs`, `cloudflare/room-shard.mjs`, both fallbacks). Zero other paths accept seed material; a grep for the seed env names returns exactly the factory, the entry points, the example-env doc, and the test suite.
- **Boot tells the truth in one line.** Every boot logs exactly one signer-state line — `armed ref=<ref> pubkey=<fingerprint>` (fingerprint only, never seed bytes, never the full pubkey in logs beyond the published fingerprint form the runbook defines), `dormant-unarmed`, or fails. Three hard numbers: present-but-invalid seed → boot failure **100%** of constructions (never a silent unsigned boot); `REQUIRED` flag set + seed absent → boot failure **100%**; flag off + seed absent → boots dormant with production behaviour **byte-identical** to today (`signed: []`, 0 stamped rows — A2 Leg 1 reproduced against the channel build).
- **Armed means signed, measurably.** After G4, one small production movement of a signable kind returns a non-empty `signedReceiptIds` (length ≥ 1) on its public face, its journal rows are stamped, and the receipt verifies **offline** — `verifyBountyReceipt` → `{ok:true}` against the published pubkey with no server call — while a one-character tamper of body or signature verifies `{ok:false}`. The A2 drill numbers are the acceptance shape: 4 signed on the payout path, 5 on dispute, 3 on timeout-refund, 12/12 across legs.
- **No seed ever touches an agent surface.** The seed value appears in exactly two places in its life: John's custody and the Worker secret store. It appears **0 times** in the repo, in any log line, in any room post, in any PR body, and in any file on this VM. The fleet only ever handles `pubkeyHex`, `ref`, and the fingerprint. Any artefact containing a 64-hex string that is not a published pubkey or a labelled TEST seed fails acceptance on sight.
- **Honest scope, printed.** Fantastic for this piece is *provisionable + armed-when-John-says*, not *every movement signed*: the approve / fee / bond-return coverage caveat (§2) remains true after arming and is stated wherever this piece's completion is reported. Nor does arming retro-sign anything: pre-arming history stays unsigned permanently, by design (S1 one-pager §4).
