## 1. The piece

The browser test surfaces are Project Room's only executed proof that the rendered product a human sees still matches the product the server code intends. Three layers, all verified at `aaa749065a`:

**A. The six browser shards (behavioural fixtures).**
- Suite membership is *derived from disk*, not hand-listed: `scripts/browser-suites.mjs` — every `scripts/*-check.mjs` is in the suite unless named in `BROWSER_SUITE_EXCLUSIONS` with a checkable reason; `package.json` `test:browser` = `node scripts/browser-suites.mjs --run`, `test:browser:ci` = `node scripts/browser-ci.mjs`.

PR runs are **label-gated**: heavy jobs run only on non-draft PRs carrying `ready-to-land`; an unlabelled/skipped run is by design, not evidence. ## 3. What fantastic means

- **Zero stale-fixture reds:** over the next 20 composed CI generations after this pack lands, no generation fails a browser shard for a fixture/baseline that diverges from the product code in its own base tree. The #5090 shape — product change merged, fixtures taught later in a separate, unconnected PR — is **mechanically impossible**, not merely discouraged: a PR that changes a mapped product surface without its paired fixtures/baselines (or an explicit, reviewed no-impact marker) fails CI before it can merge.
- **Every gated action has its paired assertions:** for each state-gated UI action (magic recovery is the type specimen), the suite contains both the negative (unearned ⇒ absent, count 0) and the positive (earned through the real product flow ⇒ present and usable) test, in the same suite file.
- **Baselines are provably CI-canonical:** 100% of committed baseline PNGs originate from a CI capture (`visual-baselines.yml` dispatch or the marker flow on a branch); zero locally captured PNGs committed; the refresh marker never reaches main (guard already exists — keep it green).
- **Visual evidence is read correctly:** any {browser} verdict cites a direct-get-verified hosted run id + head SHA (the 40618878289 standard); local pixel counts are never cited as regression evidence; an identical px count across unrelated diffs is recognised on sight as the shared-base/stale-baseline signature.
- **DOM regressions caught without a browser:** the F5 fingerprint check runs in <5 s in the ordinary (non-browser) gate, catches a removed form, a stripped `aria-live`, and an unlabelled field with 0 false positives on the current door pages, and its expectations update only in the same PR as the HTML change they describe.
- **Shards finish with headroom:** heaviest shard's measured CI duration ≤ 80% of its timeout cap (≤16 min against a 20-min cap, or the cap is raised/rebalanced until that holds), so a timeout cancellation is never again mistaken for a product red.
- **Latency/scale numbers already met stay met:** visual gate budget stays 1.00% at 1280×800; detector self-test still proves altered ⇒ fail, identical ⇒ pass.
