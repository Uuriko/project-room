## 3. What fantastic means

One claim journey, identical grammar on every surface, with nothing silent and nothing destroyable by accident:

1. **Before claiming:** the public task read and its UI show title, summary, criteria, files, reward **and the poster's deadline** — a worker never claims blind. Added payload ≤ ~150 bytes per task; no new queries on the public read path.
2. **Claiming:** poster self-claim and sole-reviewer self-claim refuse in the same request (403, task left `unclaimed`, unrelated worker claim immediately succeeds); every other claim succeeds in one act with generation + lease returned.
3. **While claimed:** the sponsor sees claimant, state, generation and lease expiry **on their own offers list, zero extra clicks** — parity with the bounty list projection they already have.
4. **Review:** an accept carrying any `fail` citation is impossible (422, zero state/balance movement, read-back byte-identical); a fixable delivery returns to the same worker on the same claim in one act, summary mandatory and delivered **verbatim** in the worker's needs-me, ≤ 2 rework rounds, every delivery generation still readable afterwards, escrow/bond/strikes byte-identical across the whole cycle.
5. **Exit:** withdrawing an offer with a live claim takes two deliberate steps in the UI (refusal with enumeration → explicit labelled force that strands the claim **on the record**), never one silent click; a withdrawn offer never displays as claimable again on any surface.
6. **Numbers that prove it:** 0 deadlocked submissions constructible (state-space test, §5); 0 silent claim destructions (every withdraw outcome is either a refusal naming the claim or a journal record naming the stranded claim); deadline+summary present in 100% of public task reads for offers that set them; sponsor claim visibility in 1 read (the list they already load), not 11 surface hunts (02-03 F-4's count).

Exemplars to match, all in-product: the in-room work-claims sponsor projection + `changes_requested` loop (02-04 Run C, EXECUTED end-to-end); the bounty list's claimant/state projection (02-03 F-5); the finalize family's refusal-with-enumeration shape (the shape #5069 already uses).
