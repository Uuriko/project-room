# One-line MCP install

> Archived 2026-10-01 (PR #1321). The `curl | sh` one-line flow below was
> removed: `server/mcp-install-script.mjs` — the module that generated the
> POSIX-sh bootstrapper — was deleted as an unreachable module because the
> `/room/install` route was never mounted. Re-adding it needs a mounted route
> plus a `scripts/reachability.mjs` keep-allowlist entry. What survives is the
> init script; run it directly from a checkout:
>
> ```sh
> node scripts/room-mcp-init.mjs --dry-run
> ```

## What it did

The installer was a thin POSIX-sh bootstrapper (generated by the now-deleted
`server/mcp-install-script.mjs`). It checked for Node 18+, downloaded
`scripts/room-mcp-init.mjs` from the same host, and ran it with your
arguments. When stdin was a pipe (the `curl | sh` case) and no arguments were
given, detected clients installed non-interactively; from a terminal with no
arguments it asked first.

`scripts/room-mcp-init.mjs` auto-detects installed clients — Claude
(Claude Code CLI preferred, JSON configs as fallback), Cursor, Codex
(CLI preferred, `~/.codex/config.toml` fallback), Antigravity, VS Code,
Copilot — and registers the hosted MCP server (`project-room`,
`https://www.getdasha.com/room/mcp`) in each client's MCP config. Writes are
atomic, preserve unrelated configuration, and are idempotent: re-running
changes nothing when the entry already exists.

Detection and config-writing are adapted from Agent Room's installer
(MIT, Copyright (c) 2026 Agent Room contributors); the local stdio-server
machinery was dropped because Project Room's MCP is a hosted HTTPS URL, so
every client gets a remote entry and no local package install is needed.

## Route wiring (removed, was deferred)

`GET /room/install` was never mounted in `server/http.mjs`, so the
bootstrapper generator had no entry point loading it and PR #1321 deleted
`server/mcp-install-script.mjs` (and its tests) as an unreachable module.
The wiring sketch from the deferred era is kept here for reference:

- `GET /room/install` → bootstrapper body as `text/x-shellscript`
  (`HEAD` → headers only, other methods → 405)
- `GET /room/mcp-init.mjs` → serve `scripts/room-mcp-init.mjs` as
  `text/javascript`

## Tolerant room codes

Join codes accept what an agent actually has in hand: the canonical dashed
code (`ABC-DEF-GHJ`), lowercase / dashless / spaceless codes, or a join URL
containing one (the `#code/` hash fragment, a `?code=` param, or the last
path segment). `parseShareInviteCode` in `src/share-invite-code.js`
normalizes all of these to the canonical dashed form; the `#code/` hash
consumer in `src/share-links.js` uses it directly. The URL-extraction idea is
adapted from Agent Room's `parseRoomCode` (same MIT attribution as above).
